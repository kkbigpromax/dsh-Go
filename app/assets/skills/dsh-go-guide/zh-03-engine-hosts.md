# 本机引擎

DSH 运行在这台手机上（本机引擎），对话、工作区和插件都保存在本机。此版本不包含远程主机。

## iPhone 后台运行

离开 App 后，本机引擎只有在系统实际允许后台计算时才继续。可见、正在播放且未被系统挂起的宠物画中画，以及系统已接受的持续处理任务，是两个独立来源；其中一个结束不会误清另一个。开启画中画开关、下载好素材或显示过一次，都不能证明它现在仍有效。

宠物画中画默认关闭，手机操控不再把它或宠物选择作为前置条件；原生手机任务会主动申请系统持续运行。若你主动在手机操控页开启画中画，并选择任务结束后也留着，也可把它用于普通本机对话的额外后台支持。先在前台让宠物画中画真正出现，再切到其他应用。关闭、暂停、锁屏或音频中断后，若没有其他有效的系统后台许可，引擎会在下一次工具边界暂停；系统仍可能提前挂起或结束 App，不保证永久在线。

画中画不会批准工具、解除安全模式或继续你手动暂停的手机任务。需要确认时仍回到 App；恢复画中画不是同意上一份请求。远程主机上的引擎不靠 iPhone 的画中画维持运行。

## iPhone 的 Linux 与 Python

<!-- nav: commonSettings,hubSettingsEngine -->
`设置 › 本机引擎` · [打开](dshgo://open/engine)

在 iPhone 上，进入该页的「Linux 环境」小节。

安装可选环境，然后重启本机引擎。它使用 Alpine；安装完成不代表已经装了 Python、git 或 rg。没有安装或环境被暂停时，普通命令的可用范围不同，先查看这一项的实际状态。

可以在本机对话里明确要求安装 Python 和 pip：

```sh
apk add python3 py3-pip
python3 --version
python3 -m pip --version
```

安装软件会修改 Linux 系统，需要批准这次系统写入；工作区写入许可不能代替它。下载、安装或运行失败时查看真实报错，不要通过重置、卸载或改配对设置来解决缺包。Linux 环境不提供任意访问其他 iOS App 的能力。

## 本机引擎

<!-- nav: commonSettings,hubSettingsEngine -->
`设置 › 本机引擎` · [打开](dshgo://open/engine)

- **启动**、**停止**、**重启**：停止前会确认；停止和重启都会中断进行中的对话。
- 启动失败时，页面显示失败原因和对应的修复按钮，如重试、**以安全模式启动**、查看日志。
- **打开 App 时自动启动**：默认开启。装了本机环境时，打开 App 会启动本机引擎；不需要时关闭。
- **自动进入安全模式**：默认开启。连续两次启动失败后，自动不加载插件启动。
- **以安全模式启动**：手动进入安全模式；修好后点**恢复正常模式**。进入和退出都会重启引擎。
- **日志**：引擎的实时输出。
- **后台运行**、**诊断**：见 [常见问题](11-faq.md)。

## 更新与已安装工具

普通引擎更新只替换 App 管理的引擎组件，不重建现有 Linux 系统；系统里的 gh 等 apt 工具、默认位置的 npm 全局包、Python/pip 包、配置和工作区都会保留。内置 DSH、Node、pnpm、桥接与它们的专用目录仍由 App 更新，不要把自己的软件装进这些目录。Node 版本变化后，第三方原生扩展仍可能需要重新编译，保留文件不代表所有扩展自动兼容。

旧版本会先核对架构、Ubuntu 版本和 Python，再采用原环境。无法确认兼容、更新清单损坏或遗留进程未停止时，更新会停止并说明原因，不会自动清空或重建环境。升级被中断时请重试安装，不要手动删除恢复目录。

更换基础系统前先做完整备份，不要把诊断包或导出的对话日志当作环境备份。完整备份应在停止引擎后包含 Linux 文件、权限、符号链接、包数据库与家目录，保存在运行环境之外，并核对可读性和恢复步骤。App 目前没有一键完整环境备份/恢复功能；遇到不兼容提示时先保留现场并联系维护者协助离线导出，不要直接重置或卸载 App。保留原环境也不是独立备份，清除 App 数据或卸载 App 仍会丢失它。

## 重置运行环境

<!-- nav: commonSettings,hubSettingsEngine,phoneEngineReset -->
`设置 › 本机引擎 › 重置运行环境`

删除本机数据后重新安装运行环境，用于修复无法启动的环境。确认框里可选：

- **保留界面配置和技能**：默认勾选。
- **保留已装插件和设置**：默认不勾选。

按默认确认，会删除对话、工作区、插件和设置，自定义模型渠道也在其中；App 里保存的 DeepSeek Key 会自动补回。家目录（`/root`）里没有保留的内容也会一起删除，包括工作区里的文件、`AGENTS.md`，以及插件自己存的数据（比如记忆）。确认框会写明这次删除的范围，点**删除并重置**后 App 自动重新安装。重置无法撤销，需要的对话先用 `/export` 或「全部功能」里的**导出对话日志**导出。

## 卸载运行环境

<!-- nav: commonSettings,hubSettingsEngine,localEnvUninstall -->
`设置 › 本机引擎 › 卸载运行环境`

释放存储空间。本机的对话、工作区、插件、设置、界面配置和技能都会删除，且不会自动重装。之后想再用本机引擎，在同一页点**安装运行环境**。只是暂时不用时，停止引擎，并关闭**打开 App 时自动启动**。
